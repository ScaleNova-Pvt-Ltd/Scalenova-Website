# ScaleNova Security & Data Privacy Standard

## 1. Security Rules

- **Zero Committed Secrets**: Secrets, API keys, passwords, or private webhooks must never be committed to GitHub.
- **Client-Side Data Sanitization**: All form inputs are sanitized client-side before processing.
- **Encrypted Transmission**: HTTPS enforced across all web traffic and API endpoints.
- **Data Privacy**: Customer databases and business records remain 100% owned by the client.
