# ScaleNova Website — Visual & UI Design System

## 1. Color Palette & Semantic Tokens

- **Brand Primary Purple**: #7F00FF (bg-brand-500)
- **Accent Steel Blue**: #4682B4 (text-brand-700)
- **Deep Space Background**: #090D16 (dark:bg-slate-950)
- **Emerald Growth Accent**: #10B981 (text-emerald-500)
- **Text Ink Dark**: #0F172A (text-slate-900)
- **Text Ink Light**: #F8FAFC (dark:text-slate-100)

---

## 2. Typography & Component Conventions

- **Primary Typeface**: Plus Jakarta Sans, sans-serif (Google Fonts).
- **Cards & Elevational Surfaces**: Glassmorphism backdrops (backdrop-blur-md), rounded corners (rounded-2xl), subtle borders (border-slate-200/80 dark:border-slate-800/60).
- **Interactive Modals**: Accessible SPA backdrop drawers with keyboard trap prevention, ARIA attributes, and unified Back navigation controls.
