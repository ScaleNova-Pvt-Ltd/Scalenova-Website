# ScaleNova Legacy Custom Applications Status

## 1. Legacy Freeze Status

Legacy custom applications created in prior repositories remain frozen and separated from the main website and client delivery architecture.

The active ScaleNova Business OS architecture utilizes standard, upgrade-safe Frappe v15 and ERPNext v15 capabilities combined with scalenova_client and plan templates (scalenova_core_os, scalenova_growth_os, scalenova_elite_os).
