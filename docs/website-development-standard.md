# ScaleNova Website — Development & Engineering Standard

## 1. Technical Guidelines

- **Vanilla Stack**: Pure HTML5, CSS3, ES6+ JavaScript. No React/Vue/Node build dependencies required for deployment.
- **Performance First**: Lazy loading of heavy visual assets, deferred Three.js library loading, reduced motion support.
- **Accessibility (a11y)**: Proper ARIA roles, keyboard focus management, label associations, and contrast compliance.
- **Maintainability**: Centralized SCALENOVA_CONFIG data object for contact details, pricing, social destinations, and backend endpoints.
